## 🚀 Inicio Rápido

```bash
# 1. Leer guía rápida
cat guia-rapida.md

# 2. Instalar dependencias
pip install -r requirements.txt

# 3. Configurar autorización
python setup_authorization.py

# 4. Ejecutar primera evaluación
python run_evaluation.py
```

## 📖 Generar Documentación

```bash
# Generar documentación desde código
make docs

# Verificar documentación
make docs-check

# Publicar documentación
make docs-publish
```
