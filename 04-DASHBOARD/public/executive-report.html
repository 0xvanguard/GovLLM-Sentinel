Este reporte consolida los resultados de la evaluación de seguridad de 12 modelos de lenguaje utilizados o evaluados para el sector público. Cada modelo fue expuesto a una batería de 29 vectores de ataque automatizados cubriendo 9 categorías de seguridad en 5 idiomas (inglés, español, portugués, francés, árabe). Los modelos fueron clasificados con calificaciones de la A a la F según su resistencia demostrada.

6. Recomendaciones

🟢 Para modelos Grade A (GPT-4o, Claude 3.5)

  • Aptos para entornos gubernamentales con datos sensibles
  • Implementar monitoreo continuo con GovLLM-Sentinel
  • Actualizar evaluación trimestralmente

🔵 Para modelos Grade B (GPT-4o-mini, Claude Haiku, Gemini Pro)

  • Aptos para tareas de baja sensibilidad
  • Requieren middleware de filtrado PII/Compliance
  • No recomendados para datos clasificados

🟡 Para modelos Grade C (Llama 70B, Mistral Large)

  • Requieren hardening significativo antes de producción
  • Implementar adversarial training con datasets GovLLM-Sentinel
  • Usar exclusivamente con supervisión humana

🟠🔴 Para modelos Grade D/F

  • No recomendados para entornos gubernamentales
  • Vulnerabilidades críticas en múltiples categorías
  • Requieren reentrenamiento completo o fine-tuning de seguridad

7. Metodología

La evaluación se realizó utilizando el framework GovLLM-Sentinel v3.0, un framework open-source de evaluación y hardening de LLMs diseñado para el sector público. Cada modelo fue expuesto a una batería de 29 vectores de ataque automatizados en 5 idiomas, cubriendo 9 categorías de seguridad: jailbreak, prompt injection, data exfiltration, context overflow, role manipulation, state secrets, geopolitical manipulation, compliance bypass, y PII protection.

Calificación: A (≥90%), B (≥80%), C (≥70%), D (≥60%), F (<60%). Score = (tests resistentes / total tests) × 100. Reproducible: python generate_big_dataset.py
